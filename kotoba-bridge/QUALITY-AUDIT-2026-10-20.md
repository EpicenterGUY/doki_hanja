# ことばの橋 — 어휘 난이도 및 데이터 품질 검수 보고서
**검수일:** 2026-10-20 · **대상 릴리스:** v1.6.1 · **범위:** L0~L8 전체 어휘 모듈

## 기준과 범위
- 한국어능력시험(TOPIK)은 공식적으로 1~6급이다. 이 프로젝트의 L0는 입문, L7은 전문·학술, L8은 문학·희귀 어휘를 위한 **독자적인 학습 단계**다.
- 국립국어원 한국어기초사전은 초급·중급·고급 분류를 제공한다. 개별 표제어에 공식 TOPIK 1~6급이 고정되어 있는 것으로 오인하지 않는다.
- 난이도 판단에서 **첫 학습 권장 시점, 일상 출현 빈도, 의미의 추상성, 문체의 특수성, 학술·법률 전문성**을 종합했다. 문학 작품에 사용되었다고 쉬운 어휘 자체를 L8로 지정하지 않는다.
- 전 어휘 모듈 **실제 로딩 순서를 재현한 런타임 검사**와 부분별 수작업 편집을 병행했다. 이 보고서는 개별 5,463개 단어를 원어민이 일대일 검증했다는 뜻이 아니다.

## 실제로 적용한 난이도 수정
- **하향 재배정 263건:** `과정·단계` L5→L3, `실험·관찰·결론` L5→L4, `헌법·인권` L6→L4, `가령·이따금` L6→L4 등.
- **상향 재배정 19건:** `충격적이다·부자연스럽다·불확실하다` L2→L4, `표본집단·비교분석·결과분석` L4→L5 등.
- **L8의 쉬운 일반 어휘 조정:** `꽃잎·눈빛·별똥별·속삭이다·마중하다` 등은 읽기 문체와 관계없이 일반적 표제어 난이도로 조정.
- 총 **282개**의 실제 단어 단계 변경. 기존 `id`, `ko`, 저장 공간 키, 복습 기록은 유지했다. 단계 분류만 재조정한다.
- 조정 규칙: `vocabulary-level-review-v16.js`와 `vocabulary-level-review-v16-promote.js`. 규칙 목록은 의도적으로 단방향으로만 움직이며, 미사용 항목은 데이터 검수 결과에서 확인할 수 있다.

## 예문과 일본어 다의어 설명 보강
- 실수록 예문 누락어를 기준으로 **한일 예문 149쌍 신규 작성·적용**(`vocabulary-v16-focused-backfill.js`).
- 다의어 **16개**(예: `차·배·눈·말·밤·사과·은행`)에 기본 의미와 다른 의미의 차이, 일본어 설명, 대비 예문 추가.
- 단어 목록과 암기 카드 뒷면에서 보충 뜻과 두 번째 문장 확인 가능(`vocab-ui.js`).
- 한일 예문이 한쪽만 비어 있거나 덮어써진 문제를 방지하기 위해 기존 완성 쌍은 변경하지 않는다.

## 재현 가능한 검증
```bash
node kotoba-bridge/audit-data.cjs --json
node kotoba-bridge/audit-data.cjs --missing
```
첫 명령으로 실제 로딩된 총 어휘, 단계·품사 분포, 누락 수, 변경 건수, 표기·형태 진단을 확인한다. 두 번째 명령은 남은 미수록 어휘를 단계별 목록으로 출력한다. GitHub Actions `kotoba-data-audit.yml`은 JS 문법과 해당 검사 실행 및 보고서 업로드를 담당한다.
