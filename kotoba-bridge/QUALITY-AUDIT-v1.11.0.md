# ことばの橋 v1.11.0 — 기본형·품사·일본어 의미 대응 검수

검수일: 2026-10-20 · 프로젝트: `EpicenterGUY/doki_hanja/kotoba-bridge/`

## 수정 방향
- 유의어·동형이의어의 여러 뜻을 단일 일본어 번역으로 합쳐 잘못 학습하는 문제를 줄인다.
- 원래 단어 카드의 `id`, `ko`, 학습 단계 및 복습 기록을 그대로 유지하고 일본어 뜻풀이, 한국어 예문, 일본어 번역 및 대조 설명만 수정한다.
- 카드에 `senseNote`와 `altExampleKo / altExampleJa`를 실어 단어장·플래시카드뿐 아니라 정답 확인 후의 주관식/객관식에도 의미 구분을 표시한다.

## 실제 적용
- **15개 고급 표제어**의 뜻풀이·문형·의미 구별 설명을 점검하고 스크립트 `vocabulary-v21-sense-quality.js`에서 **15개 모두 적용**.
- 대표적인 실질 교정: `유의하다`의 주된 품사와 일본어 뜻을 「形容詞 / （統計）有意だ」로 표시하고 예문을 통계적 유의성 문장으로 교체. 별도의 「留意하다 / 注意する」는 대비 예문과 설명으로 제공하여 두 동형어를 혼동하지 않도록 함.
- `유의미하다`의 일상적 「意味がある」와 통계적 「有意」 의미를 구별하고 양쪽 예문을 제공.
- `공시`는 기업 정보 「開示」와 제도적 「公示」 용례를 대비해 설명.
- `감사`는 「監査」 카드의 의미를 유지하되 동일 표기의 「感謝」 사용을 대비 예문으로 소개.
- `대두하다`와 `기인되다`는 출처 자료에서 확인되는 동사 용례가 있어 지우거나 잘못된 기본형으로 단정하지 않고 문형·용례 주석을 추가.
- `기인하다, 귀속하다, 귀속되다, 종합적, 주관적, 기대수명, 평균수명, 상관관계, 인과추론`의 뜻과 문맥 차이를 추가로 설명.
