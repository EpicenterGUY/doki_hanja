## 검수 방법
- 사용 중인 어휘 모듈의 실제 스크립트 로딩 순서를 재현해 변경 사항을 적용한 후 총 단어 수, 예문 수록, 누락, 중복을 집계했다.
- 기존 단어의 `id`와 기존에 완성된 한국어·일본어 예문은 변경하지 않고, **둘 다 비어 있는 경우에만** 새 예문을 적용했다.
- 각 새 예문의 한국어 표제어가 바로 전 버전의 누락 목록에 존재하는지 대조했고, 추가 후보 전부가 실제로 적용되는지 검사했다.
- 구조·수록 필드 검증은 실시했으나, 모든 문장의 독립적인 일본어 모국어 감수나 모바일 실기기 조작 검사를 마쳤다는 의미는 아니다.

## 자동 품질 검사
`audit-data.cjs`는 v1.8 L4·L5·L6 각각의 **실제 적용 건수**를 표시하며, 예문이 이미 100%인 `L0–L4`, `L7–L8`의 예문 누락이 다시 발생하면 구조 검사에 오류를 추가한다.

```bash
node kotoba-bridge/audit-data.cjs --json
node kotoba-bridge/audit-data.cjs --missing
```

GitHub Actions의 `kotoba-data-audit.yml`은 코드 문법과 위 검사 결과의 보관을 담당한다. 실제 GitHub Actions 실행 로그와 공개 기기별 UI까지 이 문서에서 검증한 것은 아니다.
